# مصنع الجوكر 2000 — دفتر الحسابات (نسخة أولية)

## ما الموجود في هذه النسخة؟
- واجهة عربية متجاوبة للكمبيوتر والموبايل.
- تسجيل دخول وإنشاء حساب.
- دفاتر تجار مستقلة.
- رصيد أول المدة.
- تسجيل بيع عبايات/إسدالات، تحصيل، خصم، مديونية إضافية ومرتجع.
- حساب الرصيد تلقائياً وكشف حساب قابل للطباعة أو الحفظ PDF.
- قاعدة بيانات سحابية عبر Supabase مع أدوار owner/accountant/staff وسياسات RLS.

## مهم قبل الاستخدام الحقيقي
هذه ملفات المشروع وليست موقعاً منشوراً بعد. لا يمكن تفعيل الحفظ السحابي أو مشاركة الحسابات حتى تنشئ مشروع Supabase وتضع بيانات الاتصال وتنشر الملفات على استضافة HTTPS. لا تضع Service Role Key في الواجهة؛ استخدم anon/publishable key فقط.

## إعداد Supabase
1. أنشئ مشروعاً في https://supabase.com
2. افتح SQL Editor وشغّل كامل ملف `supabase-schema.sql`.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. ضع القيم في `config.js` بدلاً من النصوص التجريبية.
5. من Authentication > URL Configuration أضف رابط الموقع المنشور إلى Site URL و Redirect URLs.
6. أنشئ حسابك من شاشة التطبيق. ثم في SQL Editor نفّذ:
   `update public.profiles set role='owner' where email='بريدك';`
7. أنشئ حساب المحاسب، ثم رقِّه:
   `update public.profiles set role='accountant' where email='بريد المحاسب';`
   الحسابات الأخرى تكون staff افتراضياً. ملاحظة: شاشة إدارة المستخدمين حالياً إرشادية؛ تعيين الأدوار يتم من لوحة Supabase.

## النشر
ارفع محتويات المجلد إلى استضافة صفحات ثابتة تدعم HTTPS مثل Netlify أو Vercel أو Cloudflare Pages. لا ترفع مجلد المشروع كاملاً مع ملف ZIP؛ ارفع الملفات الموجودة داخله.
يمكن تجربة الموقع محلياً عبر خادم ملفات ثابت، لأن الصفحة تستخدم ES modules:
`python -m http.server 8000`
ثم افتح `http://localhost:8000`.

## تنبيهات محاسبية
- الرصيد = رصيد أول المدة + المدين - الدائن.
- البيع والمديونية الإضافية تزيد رصيد التاجر.
- التحصيل والخصم والمرتجع تقلل الرصيد في هذه النسخة الأولية.
- اختبر الحسابات ببيانات تجريبية قبل إدخال أرصدة المصنع الفعلية.
- النسخة الحالية لا تتضمن بعد فواتير متعددة الأصناف، مزامنة مخزون، أو سجل تدقيق متقدم.
